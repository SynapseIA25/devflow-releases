The four pillars

Not an AI chat. A platform to manage the entire project.

Each piece builds on the last: experts that coordinate, flows that run them, environments that isolate them, and a hub that governs it all per project.

9 roles

Team of expert agents

Architect, Frontend, Backend, Database, DevOps, SRE, Security, QA and Product. A lead breaks the task down, delegates each part to its specialist in its own session, and synthesizes the result.

Graph

Workflow orchestrator

Chain agents, commands and triggers as a graph of nodes with named variables. Loops, branches and webhooks to automate your project's repeatable tasks.

Isolated

Test environments

Each agent works in an ephemeral git worktree: it tests, writes and breaks things without touching your code. Review the diff and promote to the real project with one click, or discard it without a trace.

Per project

Project Hub

Detected stack, structure, docs, services, terminals and tech debt — all scoped per project. Register multiple projects, each with its own environment, agents and flows.

The safe loop

Delegate without fear.

The cycle that keeps letting several agents work in parallel from ending in a broken project.

01 · DELEGATE

The lead splits it up

You describe the task; the lead agent breaks it down and assigns each sub-task to the right expert by area.

02 · ISOLATE

They run in an environment

The experts run inside an ephemeral worktree, in parallel, with no permission to touch your real project.

03 · PROMOTE

You have the final say

Review the consolidated diff and promote to the base branch or discard it. Merge conflicts are shown before applying.
